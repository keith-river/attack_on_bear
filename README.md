# 進撃のベア / attack_on_bear

ある日、森の中で、突然クマとエンカウントしたら——。

地域課題（気候変動・自然破壊・人とクマの共生）について考えるきっかけとして試作した、ブラウザだけで遊べるミニゲームです。「地域課題×生成AI×ナッジ実験」Advent Calendar 連載記事と連動しています。

## デモ

🎮 **公開URL（GitHub Pages）：** https://keith-river.github.io/attack_on_bear/

## これは何か

- 森でクマと遭遇した状況をランダム生成し、制限時間内に10種類の行動から1つを選ぶシミュレーションゲームです。
- クマの感情・周辺環境・選んだ行動・ランダム要素の掛け合わせで結果が決まり、「唯一絶対の正解はない」という手触りを意図的に残しています。
- 研究成果物ではなく、**地域課題について議論を始めるための試作版（プロトタイプ）**です。

詳しい狙いや背景、遊んだ後に考えてほしいことについては、連載記事をご覧ください。

📄 **記事本文：** [`article.md`](./article.md)

## 遊び方

1. [公開URL](https://keith-river.github.io/attack_on_bear/) を開く
2. 難易度を選び、「ENCOUNTER START」を押す
3. クマの様子・周辺環境を見て、制限時間内に行動を1つ選ぶ
4. ゲームオーバーまたはクリア後に表示される「行動の振り返り」を確認する

## ディレクトリ構成

```
attack_on_bear/
├── docs/              GitHub Pages で公開しているアプリ本体
│   ├── index.html
│   ├── style.css
│   └── app.js
├── article.md         連載記事の原稿（Markdown）
├── README.md          このファイル
├── LICENSE.txt         ライセンス（MIT）
└── .gitignore
```

GitHub Pages は `main` ブランチの `/docs` フォルダから配信される設定を想定しています（リポジトリの Settings → Pages で `/docs` を指定してください）。

## 使用技術

- HTML5 / CSS / JavaScript（フレームワークなし・単一ページのSPA）
- Python / Jupyter（企画段階での検討・試作補助）
- 生成AI支援開発（後述）

## 技術的な見どころ

1. **「熊の感情 × 周辺環境 × 選んだ行動 × ランダム要素」の掛け算による判定ロジック**
   状況によって同じ行動の評価が変わる、単純な正解当てゲームにしない設計。
2. **フル JavaScript・ビルド不要のシングルファイル構成**
   `docs/` 以下の3ファイルのみで完結し、GitHub Pages にそのまま配置できる。
3. **ゲーム終了後の「行動の振り返り」機能**
   プレイ内容をその場で振り返り、議論のきっかけに接続する導線。

## 生成AI活用について

地域課題の設定とゲームとしての設計思想は筆者が考え、実装（HTML/JavaScriptのコーディング）には生成AIを活用しています。対話とレビューを繰り返しながら挙動や文言を調整し、最終的な内容確認・公開判断は筆者が行っています。詳細は [`article.md`](./article.md) の「生成AI活用について」をご覧ください。
